# Heating Fuel Useful Heat Calculation

This example calculates the useful heat delivered to a home from fuel consumption, considering heating system efficiency. It demonstrates how to separate the total energy consumed from the actual heat that warms the living space, highlighting energy losses due to inefficiency.

## Language

`python`

## How to Run

Save the code as `main.py`. Run from your terminal: `python main.py`
